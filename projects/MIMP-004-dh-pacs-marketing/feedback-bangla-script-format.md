For any spoken Bangla wording (demo scripts, voiceover), write **প্রমিত চলিত in Bengali script as the main text**, with আপনি. English nouns stay English, the way Bangladeshi professionals say them (CT, workstation, link, PACS said *pyaks*). Only the few **anchor lines** (said word for word) get the three-line format: বাংলা → romanized → English. Everything else is short Bengali prompts. Pronunciation notes go only on the words that slip (e.g. অভিজ্ঞ *ob-hig-go*, প্রশ্ন *prosh-no*). No text-to-speech audio.

**Why:** Maidul is a native speaker. Full romanization slows him down, and a fully memorised script sounds recited, which a manager hears as a vendor. Confirmed in the 2026-09-26 Ibn Sina session.
**How to apply:** build printable Bangla as HTML, not Word, because the browser shapes conjuncts (জ্ঞ, ক্ষ, ন্ত) correctly and Word often doesn't. See [[project-ibnsina-branch-manager-plan]].
