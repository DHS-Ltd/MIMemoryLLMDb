The website blueprint (DH_PACS_WEBSITE_CONTENT_BLUEPRINT.md) was reviewed and the following decisions were agreed. These have NOT yet been applied to the blueprint file — they need to be implemented in a future session.

**Agreed changes to the blueprint:**

1. Hero headline — SOFTEN
Agreed: Remove "Every Single Print Is Clinically Obsolete." Confrontational language toward a relationship-driven Bangladesh B2B audience. Lead with the opportunity and cost (৳14.6 billion), not a judgment on what they currently do.

2. "Bangladesh Is Next" framing — CHANGE
Agreed: Replace with a leapfrog/leadership narrative. Bangladesh has the opportunity to skip the CD/film era entirely. Lead with pride and forward momentum, not the implication that the country is always catching up.

3. HIPAA reference — KEEP, but phrase carefully
Agreed: Keep HIPAA in website copy. Bangladesh hospital decision-makers know it and aspire to it. Phrase as "built to HIPAA standards" (accurate — open-source stack is HIPAA compliant) not "HIPAA certified" (not yet accurate at company level). See [[dh-pacs-hipaa-compliance]].

4. Patient card as standalone B2B audience — REMOVE for now
Agreed: This is a B2B sale. Patients are end beneficiaries, not buyers. Patient benefit should appear inside the hospital card ("your patients receive..."), not as a co-equal audience card. Future B2C segment to be addressed later when that stage is reached.

5. ৳14.6 billion film market figure — SOURCE IT
Agreed: Source from NBR (National Board of Revenue) Bangladesh import data, HS code 3701.10 (sensitised X-ray film). If import data gives a different number, use the real number. On the website, frame as: "৳14.6 billion in medical imaging film annually (NBR import data, [year])."

6. Radiology IT Consulting service card — DOWNGRADE OR REMOVE
Agreed: Having consulting as a co-equal service alongside the product dilutes the product story at this stage. Either demote to a footnote or remove from the homepage entirely. Focus on the product.

7. Pricing — DEFER, to be added later
Agreed: Exact per-patient pricing numbers are in the user's physical notebook. Pricing strategy session to be completed before this is added to the website. See [[dh-pacs-pricing]].

8. BDC (diagnostic center) and Fitness Tracker — OMIT ENTIRELY
Agreed: Do not include either in the website. The website is focused on DH PACS. No mention of BDC or the fitness tracker project.
